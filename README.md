# 満員御礼 ― コンサートプロモーター物語

コンサートプロモーター（イベンター）の仕事を体験しながら学べるブラウザゲームです。
`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## ルール
- 関門：決められた週までに順位を上げないと、ライバルに買収されてゲームオーバー（「ふつう」は第20週までに3位以内、第36週までに2位以内。4週間の猶予あり）
- 事務所の固定費が毎週かかる（時期が進むほど増える）
- 1年（52週）で、ライバル3社と資産を競い、業界No.1を目指す
- 公演は2本まで同時進行（信頼度40で3本）。行動力は毎週3つ
- 資金がマイナスになると倒産

## 主な機能
- 先輩プロモーターのガイド（チュートリアル）／難易度3段階（やさしい・ふつう・むずかしい）
- 複数公演の同時進行と、スマホ用のタブ切り替え
- ジャンル別の本番ミニゲーム（点火タイミング・ペンライト色合わせ・連打・静寂からの反応）
- ライバル社長の顔とセリフ、日程の取り合い（上乗せ交渉）
- 季節イベント（企画代行・新人発掘・夏フェス・冠スポンサー・年末特番）
- 演者との信頼関係（出演料の値引き・日程の優先）
- 知識バッジ14種、用語手帳
- 先行抽選・招待券・前売代金の入金タイムラグ・つなぎ融資・法人税
- BGMと効果音、演者の画像の差し替え
- スタッフ雇用（人件費＝固定費と引き換えの永続効果）と、数週間ごとに届く依頼（ミッション）
- 宣伝の「飽き」「メディアミックス」「勢い」、販売途中の値上げ・値下げ（1回まで）
- 難易度ごとの自己ベスト記録
- 会場イラスト、資産の推移グラフ、週替わりの速報、需要とキャパの比較ゲージ、レーザーと動く演者のライブ演出
- 本番前のセットリスト作り（盛り上がりの波に曲のテンポを合わせるパズル）
- 企画画面の図解化（能力バー、契約・演出のイラストカード、資金の積み上げグラフ、黒字ラインつき需要ゲージ）
- 公約（満員を宣言して勝負に出る）、連続満員ボーナス、伝説の夜、ライバル対決の勝敗、今週のチャンス
- ジャンルのトレンド（ブームと低迷）と、ライバル公演との日程の重なり（競合公演）

## 1公演の流れ
1. **企画（ブッキング）** … 演者・会場・日程を押さえる。人気の日程はライバルに取られていく
2. **契約と価格** … 固定ギャラ／歩合、チケット価格、演出グレード。損益分岐点を確認
3. **資金集め** … 借入・協賛・共同主催・クラウドファンディング・興行中止保険
4. **宣伝** … 媒体ごとに得意な客層が違う。熱量（話題度）を上げてチケットを売る
5. **グッズ発注** … 本番3週前が締め切り。在庫リスクと機会損失
6. **本番** … タイミングよく「点火！」で演出を決めるミニゲーム
7. **収支報告** … お金の流れ（滝グラフ）と振り返り
