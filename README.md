# 満員御礼 ― コンサートプロモーター物語

コンサートプロモーター（イベンター）の仕事を体験しながら学べるブラウザゲームです。
`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## ゲームの流れ（1公演ごと）
1. **演者を選ぶ** … 動員力・出演料・物販人気を比べる
2. **会場と日程を押さえる** … キャパと動員力のバランス、演者と会場の空き日程を合わせる
3. **契約とチケット** … 固定ギャラ／歩合、チケット価格、演出グレード。損益分岐点を確認
4. **資金を集める** … 銀行借入・協賛スポンサー・共同主催（出資）・クラウドファンディング
5. **宣伝とチケット販売** … 毎週3回まで宣伝。媒体ごとに得意な客層が違う。ランダムなトラブルにも対応
6. **グッズ発注** … 公演3週前が締め切り。在庫リスクと機会損失のバランス
7. **公演当日と収支報告** … 損益計算書と「振り返り」で学ぶ

全6公演で最終資金の大きさがランク（D〜S）になります。資金がマイナスになると倒産です。
